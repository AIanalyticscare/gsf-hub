This site is the working knowledge base for the GSF Hub WordPress platform. It brings the technical source reference, role-based user guides, and video tutorials into one searchable place.

## Choose where to start

- **Developers and technical maintainers:** begin with [Technical WordPress](./technical/overview.md).
- **Members and visitors:** use the [End-User Guide](./user-guides/end-user-guide.md).
- **Content and programme staff:** use the [Staff Content Operations Guide](./user-guides/staff-content-operations-guide.md).
- **Site administrators:** use the [Administrator Guide](./user-guides/administrator-guide.md).
- **Visual learners:** open the [Video Tutorials](./video-tutorials/overview.mdx).

The Git repository stores custom source code and documentation. Production databases, member data, uploads, migration backups, and large course packages are deliberately kept out of version control.
