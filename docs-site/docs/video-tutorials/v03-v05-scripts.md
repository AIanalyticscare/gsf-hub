These approved scripts are ready for recording. Each one includes the intended workflow and verification steps.

## V03 Add and update a resource

1. Open **Resources**, then add a resource or select an existing one.
2. Enter the title and a concise summary.
3. Assign resource type, topic, geography, language, and publication year.
4. Add the source and the approved file or public URL.
5. Choose a featured image and meaningful alternative text.
6. Preview and publish or update the resource.
7. Test the public card, metadata, filters, and access link.

## V04 Create or update an online course

1. Open **Learn**, then **Courses**.
2. Add the course title, purpose, audience, and learning outcome.
3. Add an approved image and alternative text.
4. Attach the correct approved course package.
5. Confirm enrollment and access settings.
6. Set the catalogue position.
7. Publish and launch the course as a learner.
8. Complete the required activity and verify progress.
9. Confirm that the certificate is correct and downloads successfully.

## V05 Manage Data Centre projects

1. Open **Data Centre**, then **Projects**.
2. Enter or review project details against the approved source.
3. Upload data using the required template and formats.
4. Resolve every validation warning or error.
5. Publish or update the checked project.
6. Verify the public filters, map, summary, indicators, and related displays.
7. Download the project data and confirm its contents.
