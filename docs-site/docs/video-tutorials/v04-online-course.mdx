## Learning outcomes

- Open the Learn and SCORM administration areas.
- Import an approved course package.
- Create or update the course description and featured image.
- Configure learner access, duration, catalogue order, and certificate availability.
- Publish and launch the course as a learner.
- Verify completion tracking and certificate download.
