## Learning outcomes

- Open the Case Studies area and create or update an entry.
- Enter the title and summary.
- Select the type, project, focus area, geography, and date.
- Add organizations, partners, files, links, and an image.
- Publish or update the case study.
- Test the public case study and its supporting links.
