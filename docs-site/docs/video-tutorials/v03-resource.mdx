## Learning outcomes

- Open the Resources area and create or update a resource.
- Enter the title and summary.
- Select the type, topic, geography, language, and year.
- Add the source, approved file or URL, and featured image.
- Publish or update the resource.
- Test the public resource, its metadata, and its access link.
