WordPress code and WordPress content have different sharing requirements. Git is appropriate for custom themes, custom plugins, configuration examples, documentation, and repeatable setup scripts. It is not the right place for production member records or unrestricted database exports.

## Included in Git

- Custom theme and plugin source
- Docker development configuration
- Setup and migration documentation
- Public-safe examples and CSV templates
- Documentation source, screenshots, captions, and tutorial videos

## Shared separately

- Production database exports
- WordPress uploads and member media
- Migration backups
- Generated operational exports
- Large SCORM and course packages
- Secrets and environment files

Before sharing a content migration, confirm the recipient, access controls, retention period, and whether personal data must be removed.
