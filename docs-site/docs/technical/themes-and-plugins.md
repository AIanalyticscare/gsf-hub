## Themes

The main `gsf-hub` theme provides the public templates, search and archive views, expert and project templates, responsive navigation, and the primary visual system. The `gsf-hub-sunrise` theme is an alternate presentation layer, while `gsf-hub-assistant-child` integrates the resource assistant with a small child-theme surface.

## Custom plugins

| Plugin | Responsibility |
| --- | --- |
| `gsf-content-staff-role` | Content-staff permissions |
| `gsf-course-catalogue-order` | Course ordering controls |
| `gsf-data-centre` | Project, indicator, evidence, chart, and import/export workflows |
| `gsf-hub-expert-workflow` | Expert profiles and workflow |
| `gsf-hub-transfer` | Controlled content transfer support |
| `gsf-learn-feedback-gate` | Feedback and course-completion gating |
| `gsf-mobile-header-actions` | Mobile header actions |
| `gsf-resource-recommendation-assistant` | WordPress recommendation interface |
| `gsf-scorm-lite` | SCORM course delivery and tracking |

Third-party plugins are not committed. Install approved versions through the deployment process and record any version requirements before upgrading.
