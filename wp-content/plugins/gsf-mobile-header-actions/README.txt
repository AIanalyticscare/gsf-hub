GSF Mobile Header Actions
=========================

Purpose
-------
Makes the existing GSF Hub language selector and Sign in/Log out button visible
when the mobile navigation menu is expanded.

Installation
------------
1. In WordPress Admin, go to Plugins > Add New Plugin > Upload Plugin.
2. Upload gsf-mobile-header-actions-plugin.zip.
3. Choose Install Now, then Activate Plugin.
4. Purge any WordPress, hosting, and CDN caches.
5. Test the header while logged out and logged in on a mobile screen.

Requirements
------------
- The GSF Hub or GSF Hub Sunrise theme.
- The theme header must contain [data-nav-toggle], #primary-navigation, and
  .site-actions elements, as the current GSF themes do.

Removal
-------
Deactivate and delete the plugin. It creates no database tables or settings.
