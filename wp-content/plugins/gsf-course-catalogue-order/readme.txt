Adds a Catalogue order field to GSF Learn courses.

== Description ==

Use the Catalogue order box when editing a Learn course. Lower numbers appear
first in the public Learn catalogue. Courses with matching numbers are sorted
alphabetically.

The plugin uses WordPress's native menu_order value. It also orders the native
course archive, while deliberately leaving homepage course selection unchanged.

== Installation ==

1. Upload and activate the plugin.
2. Open Learn > Courses and edit a course.
3. Set Catalogue order and update the course.
