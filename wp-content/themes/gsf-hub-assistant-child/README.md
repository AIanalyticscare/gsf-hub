# GSF Hub Assistant Child

This minimal child theme inherits the existing `GSF Hub` parent theme and changes only the homepage search panel. It does not replace the parent header, footer, branding, site-wide CSS, or any non-homepage template.

## Requirements

- The `GSF Hub` parent theme must already be installed.
- GSF Resource Recommendation Assistant 1.0.3 or later must be installed and active.
- A published page at `/resource-assistant/` containing `[gsf_resource_assistant]`.

## Install

1. Upload the ZIP through **Appearance → Themes → Add New → Upload Theme**.
2. Activate **GSF Hub Assistant Child**.
3. Clear WordPress, server, and CDN caches.

If the Resource Assistant plugin is inactive, the original parent-theme search panel remains in place.

To roll back, reactivate the previous theme under **Appearance → Themes**. No content is deleted by activating or deactivating this child theme.
